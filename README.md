Entry for the [Funniest Lost Sock Status Update](https://make.fun/bounty/u-eager-stork-81-9647-funniest-lost-sock-status-update-4b1fa3ce) bounty on make.fun.

## What it does

`main.py` (Python 3.13, standard library only) writes one status update — at most 120 characters, in the voice of a lost sock that has ended up somewhere it should not be — to `/output/entry.txt`. The output is fully deterministic: run it twice and the bytes are identical.

## Run

```sh
python3 main.py
```
